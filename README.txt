BUILD YOUR ANDROID APP (free, no Android Studio, works from a phone browser too)
1. Make a free account at github.com and create a new repository (Public or Private).
2. Upload ALL files from this folder (keep the folders www and .github/workflows).
   Tip: on github.com choose "Add file > Upload files" and drag everything in.
3. Open the "Actions" tab. The "Build APK" run starts by itself (about 5 minutes).
   If not, click "Build APK" > "Run workflow".
4. When it turns green, open the run and download "JEE-Hours-apk" from Artifacts (a zip).
5. Unzip it, send app-debug.apk to your phone, tap it, allow "Install unknown apps", install.
The app works fully offline. Use Settings > Export to back up your data.
